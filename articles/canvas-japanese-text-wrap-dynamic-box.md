Canvas 2D APIでユーザー入力のテキストを画像に合成するツール(証明書ジェネレーター、透かし入れツール、SNS画像作成ツールなど)を作ると、ほぼ必ず次の2つの問題にぶつかります。

1. 入力文字列の長さが不定なので、決め打ちの幅に収まらず箱からはみ出す
2. 折り返した結果、行数が変わるので、箱の高さも決め打ちにできない

英語圏の実装例では単語単位(スペース区切り)の折り返しが前提になっていることが多く、日本語のようにスペースを含まない言語では素直に流用できません。個人開発のWebツールで工事写真に情報を合成する機能を作った際にこの実装を詰めたので、パターンとして整理します。

## 単語区切りの折り返しが日本語で機能しない理由

英語でよくある折り返し実装は「スペースで単語に分割し、単語単位で行に詰め込んでいく」方式です。

```js
// 英語向けの典型的な実装(日本語では機能しない)
function wrapByWord(ctx, text, maxWidth) {
  const words = text.split(' ');
  // ...単語単位で maxWidth を超えたら改行
}
```

日本語の文章にはこの「単語の区切り」に相当するスペースがありません。`text.split(' ')` は文全体が1つの「単語」として返ってくるだけで、折り返しが一切機能しなくなります(形態素解析ライブラリを使えば単語単位の分割は可能ですが、依存が増える上にオーバースペックです)。

## 文字単位 + measureTextで解く

日本語の折り返しに必要なのは「単語」ではなく「文字」を単位にした判定です。Canvas 2D APIの `CanvasRenderingContext2D.measureText()` は、指定したフォント設定で実際にレンダリングしたときのピクセル幅を返すので、1文字ずつ足しながら幅を測り、閾値を超えた時点で改行すれば、フォントや文字種(全角・半角混在)に関わらず正確に折り返せます。

```js
function wrapLines(ctx, text, maxWidth) {
  const out = [];
  // 手入力の改行(Enter)はそのまま尊重し、長い行だけ折り返す
  text.split('\n').forEach((rawLine) => {
    const chars = rawLine.split('');
    let line = '';
    for (const ch of chars) {
      const test = line + ch;
      if (ctx.measureText(test).width > maxWidth && line.length > 0) {
        out.push(line);
        line = ch;
      } else {
        line = test;
      }
    }
    out.push(line);
  });
  return out;
}
```

ポイントは3つです。

- `text.split('\n')` でユーザーが明示的に入れた改行はまず尊重する。その上で、各行を独立に折り返し処理にかける
- `line.length > 0` のガードを入れる。これがないと、1文字だけで `maxWidth` を超えるフォントサイズの場合に空文字列を `out` に積み続けて無限ループ、または空行だらけになる
- `ctx.font` は呼び出し前に設定しておく必要がある。`measureText` はその時点で `ctx` に設定されているフォント(サイズ・太さ・フォントファミリー)を使って幅を計算するため、描画時と異なるフォント設定で測ると幅がずれる

全角・半角が混在する文字列(「工事名: ABC建設」のような文字列)でも、`measureText` は実際の描画幅を返すため、全角文字を2文字分・半角を1文字分と決め打ちで概算するより正確です。絵文字や結合文字が混じるケースでは1文字扱いが崩れることがありますが、業務系ツールの入力(住所・氏名・日付など)であればこの実装で十分実用に耐えます。

## 折り返した行数から箱の高さを逆算する

行の折り返しが確定すれば、箱(黒背景の吹き出しや情報パネルなど)の高さは行数から機械的に計算できます。

```js
const fontSize = 16;
const lineHeight = Math.round(fontSize * 1.4); // 1.4 は日本語で読みやすい行間の目安
const pad = 12;

const lines = wrapLines(ctx, rawText, maxWidth);
const boxHeight = pad * 2 + lines.length * lineHeight;
```

`lineHeight` を `fontSize` の倍数で決めておけば、フォントサイズを可変にしたとき(例えば画像サイズに応じて文字サイズをスケールさせる場合)も追従します。行の描画は `textBaseline = 'top'` にしておくと、`y` 座標の計算が「上端 + 行番号 × 行の高さ」で済み、ベースライン基準のオフセット計算をしなくて良くなります。

```js
ctx.textBaseline = 'top';
lines.forEach((line, i) => {
  ctx.fillText(line, boxX + pad, boxY + pad + i * lineHeight, maxWidth);
});
```

## まとめ

- 日本語テキストの折り返しは、単語単位ではなく**文字単位 + `measureText` による実測**で判定する
- 折り返しループには「1文字も入らない行を作らない」ガードを必ず入れる(無限ループ・空行の原因になる)
- 折り返し後の行数から箱の高さを逆算すれば、入力文字数に関わらず崩れないレイアウトになる
- `textBaseline = 'top'` にしておくと行位置の計算がシンプルになる

この実装は証明書・電子黒板・SNS用画像生成など、「ユーザーが自由入力したテキストを画像に合成する」系のツール全般に流用できます。実際にこのパターンで作った電子小黒板ジェネレーター(工事写真に黒板情報を合成するツール)は現在ステージング環境で完成しており、公開まわりの準備が整い次第公開予定です。
